Основные метрики для моделей

    JSON Validity: доля корректно парсящихся ответов.
    Field Accuracy: точность ключевых полей (title, datetime, duration, location).
    Datetime Normalization: правильность часового пояса и длительности.
    URL Extraction: корректность извлечения ссылок.
    Hallucination Rate: доля выдуманных деталей.
    Tool Success: успешность вызовов инструментов (создание событий).
    ICS Validity: корректность созданных ICS-файлов.
    Latency/Cost: скорость и ресурсозатраты.
    Robustness: устойчивость к шумным входам.
    User Feedback: частота исправлений пользователем.

Ключевые риски и уязвимости

    ICS-инъекция: необработанные поля могут нарушить структуру файла. Решение: экранировать по RFC 5545 или использовать библиотеку icalendar.
    Ошибки с часовыми поясами: некорректное использование UTC. Решение: конвертировать с astimezone(pytz.UTC) перед записью.
    Неверная локализация времени: .replace(tzinfo=...) искажает время. Решение: использовать dateutil.parser.isoparse.
    Избыточные права: создание событий без подтверждения. Решение: требовать явное согласие пользователя.
    Утечки в логах: вывод персональных данных и ошибок. Решение: маскировать чувствительные поля.
    Дублирование событий: отсутствует проверка на повторы. Решение: использовать детерминированный UID.
